# コーヒースタンド HaLo 画像のおねがい（チャッピー用）

秋田市・千秋モール1Fの「自家焙煎のコーヒー豆のお店」の提案ページ用です。
**5枚**つくってください。

## 全部に共通のルール
- 写真のようなリアルな雰囲気（イラストにしない）
- **人・顔・手は入れない**
- **文字・ロゴ・店名は入れない**（キャニスターのラベル、カード、袋も無地）
- 他のお店のお菓子・パン・商品は入れない
- 雰囲気：明るい木のカウンター、ガラスや金属のキャニスター、白い壁、やわらかい自然光。落ち着いた深いグレー＋青緑が少しあると◎
- 保存形式：**WebP**（できなければJPGで大丈夫です）

## 1枚ずつ
| ファイル名 | 比率 | 内容 |
|---|---|---|
| 01_hero_counter_16x9.webp | 横長 16:9 | 木のカウンターに、コーヒー豆の入ったキャニスターがずらりと並ぶ。奥は白い壁。お店の顔になる1枚 |
| 02_cup_4x3.webp | 4:3 | 木のカウンターに置いた、ドリップしたてのコーヒー1杯（白い紙カップ or 陶器カップ、無地）。湯気が少し |
| 03_canisters_4x3.webp | 4:3 | キャニスターのアップ。ふたが1つ開いていて、焙煎豆が見える。豆の色の違い（浅め〜深め）が分かる |
| 04_beans_bag_4x3.webp | 4:3 | 無地のクラフト袋に入った豆と、小さなスコップ。横に空のマイキャニスター（持ち込み用のイメージ） |
| 05_card_4x3.webp | 4:3 | 木のカウンターに白い無地のカードが1枚、横にコーヒー豆が少し。文字は入れない |
